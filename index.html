1 Le Second Degré

1.1 Définition

Un polynôme du second degré est une expression de la forme :

f(x) = ax² + bx + c, avec a ≠ 0

où a, b et c sont des nombres réels appelés coefficients.

1.2 Forme canonique

Tout trinôme du second degré peut s'écrire sous forme canonique :

f(x) = a(x − α)² + β, avec α = −b/(2a) et β = f(α)

Le point S(α ; β) est le sommet de la parabole.

1.3 Discriminant et racines

On appelle discriminant le nombre :

Δ = b² − 4ac
  • Si Δ > 0 : deux racines distinctes x₁ = (−b − √Δ)/(2a) et x₂ = (−b + √Δ)/(2a)
  • Si Δ = 0 : une racine double x₀ = −b/(2a)
  • Si Δ < 0 : aucune racine réelle

1.4 Signe du trinôme

Le signe de f(x) dépend de a et des racines :

  • Si Δ > 0 : f(x) est du signe de a à l'extérieur des racines, et de signe opposé à l'intérieur.
  • Si Δ = 0 : f(x) est du signe de a partout sauf en x₀ où il s'annule.
  • Si Δ < 0 : f(x) est du signe de a sur tout ℝ.

1.5 Factorisation

Si Δ > 0 : f(x) = a(x − x₁)(x − x₂)
Si Δ = 0 : f(x) = a(x − x₀)²
📝 Exercice corrigé 1

Résoudre l'équation : 2x² − 5x + 3 = 0

Corrigé :

a = 2, b = −5, c = 3.

Δ = b² − 4ac = (−5)² − 4×2×3 = 25 − 24 = 1.

Δ > 0, donc deux racines :

x₁ = (5 − 1)/(2×2) = 4/4 = 1

x₂ = (5 + 1)/4 = 6/4 = 3/2

Solution : S = {1 ; 3/2}

📝 Exercice corrigé 2

Étudier le signe de f(x) = −x² + 4x − 3.

Corrigé :

Δ = 16 − 12 = 4 > 0. Racines : x₁ = ( −4 + 2 )/(−2) = 1 et x₂ = ( −4 − 2 )/(−2) = 3.

a = −1 < 0. Donc f(x) < 0 à l'extérieur de [1 ; 3] et f(x) > 0 sur ]1 ; 3[.

Tableau de signes : f(x) > 0 pour x ∈ ]1 ; 3[, f(x) < 0 pour x ∈ ]−∞ ; 1[ ∪ ]3 ; +∞[.

2 Les Suites Numériques

2.1 Définition

Une suite numérique est une fonction définie sur ℕ (ou une partie de ℕ) à valeurs dans ℝ. On note (uₙ).

2.2 Suites arithmétiques

Une suite est arithmétique de raison r si :

uₙ₊₁ = uₙ + r

Terme général :

uₙ = u₀ + n·r   ou   uₙ = u₁ + (n−1)·r

Somme des n premiers termes :

S = (nombre de termes) × (premier + dernier)/2

2.3 Suites géométriques

Une suite est géométrique de raison q (q ≠ 0) si :

uₙ₊₁ = q · uₙ

Terme général :

uₙ = u₀ · qⁿ

Somme des termes :

S = u₀ × (1 − qⁿ⁺¹)/(1 − q) si q ≠ 1

2.4 Sens de variation

  • Suite arithmétique : croissante si r > 0, décroissante si r < 0, constante si r = 0.
  • Suite géométrique (u₀ > 0) : croissante si q > 1, décroissante si 0 < q < 1.
📝 Exercice corrigé 1

Soit (uₙ) la suite arithmétique de premier terme u₀ = 3 et de raison r = 5. Calculer u₁₀ et la somme S = u₀ + u₁ + ... + u₁₀.

Corrigé :

u₁₀ = u₀ + 10r = 3 + 10×5 = 53.

Nombre de termes : 11 (de u₀ à u₁₀).

S = 11 × (3 + 53)/2 = 11 × 56/2 = 11 × 28 = 308.

📝 Exercice corrigé 2

Soit (vₙ) la suite géométrique de premier terme v₀ = 2 et de raison q = 3. Calculer v₅ et la somme des 6 premiers termes.

Corrigé :

v₅ = v₀ × q⁵ = 2 × 3⁵ = 2 × 243 = 486.

S = v₀ × (1 − q⁶)/(1 − q) = 2 × (1 − 729)/(1 − 3) = 2 × (−728)/(−2) = 728.

3 Dérivation

3.1 Nombre dérivé

Le nombre dérivé de f en a est la limite du taux d'accroissement :

f'(a) = lim (h→0) [f(a+h) − f(a)] / h

Il correspond au coefficient directeur de la tangente à la courbe au point d'abscisse a.

3.2 Formules de dérivation

  • (k)' = 0 (k constante)
  • (xⁿ)' = n·xⁿ⁻¹
  • (√x)' = 1/(2√x)
  • (1/x)' = −1/x²
  • (u+v)' = u' + v'
  • (u·v)' = u'v + uv'
  • (u/v)' = (u'v − uv')/v²
  • (uⁿ)' = n·uⁿ⁻¹·u'

3.3 Équation de la tangente

y = f'(a)(x − a) + f(a)

3.4 Variations et dérivée

  • Si f' > 0 sur un intervalle, alors f est croissante.
  • Si f' < 0 sur un intervalle, alors f est décroissante.
  • Si f' = 0, c'est un point critique (extremum possible).
📝 Exercice corrigé 1

Soit f(x) = x³ − 3x² + 2. Calculer f'(x), puis f'(1) et l'équation de la tangente en x = 1.

Corrigé :

f'(x) = 3x² − 6x.

f'(1) = 3 − 6 = −3.

f(1) = 1 − 3 + 2 = 0.

Tangente : y = f'(1)(x − 1) + f(1) = −3(x − 1) + 0 = −3x + 3.

📝 Exercice corrigé 2

Étudier les variations de f(x) = x² − 4x + 1 sur ℝ.

Corrigé :

f'(x) = 2x − 4.

f'(x) = 0 ⟺ x = 2.

Pour x < 2 : f'(x) < 0 → f décroissante.

Pour x > 2 : f'(x) > 0 → f croissante.

Minimum en x = 2 : f(2) = 4 − 8 + 1 = −3.

4 Statistiques

4.1 Vocabulaire

  • Population : ensemble étudié.
  • Caractère : propriété étudiée (quantitatif ou qualitatif).
  • Effectif : nombre d'individus d'une catégorie.
  • Fréquence : effectif / effectif total.

4.2 Moyenne

x̄ = (n₁x₁ + n₂x₂ + ... + nₖxₖ) / N

où N est l'effectif total.

4.3 Médiane et quartiles

  • Médiane : valeur qui partage la série en deux groupes de même effectif.
  • Q1 : 1er quartile (25 % des valeurs lui sont inférieures ou égales).
  • Q3 : 3e quartile (75 %).
  • Écart interquartile : Q3 − Q1.

4.4 Variance et écart-type

V = (1/N) Σ nᵢ(xᵢ − x̄)²   ;   σ = √V

L'écart-type mesure la dispersion autour de la moyenne.

📝 Exercice corrigé 1

Série : notes 8, 12, 15, 10, 14, 9, 11, 13. Calculer la moyenne et l'étendue.

Corrigé :

Somme = 8+12+15+10+14+9+11+13 = 92. Effectif = 8.

Moyenne = 92/8 = 11,5.

Étendue = max − min = 15 − 8 = 7.

📝 Exercice corrigé 2

Notes : 10 (coef 2), 12 (coef 1), 15 (coef 3). Calculer la moyenne pondérée.

Corrigé :

Total points = 10×2 + 12×1 + 15×3 = 20 + 12 + 45 = 77.

Total coefficients = 2 + 1 + 3 = 6.

Moyenne = 77/6 ≈ 12,83.

5 Probabilités

5.1 Vocabulaire

  • Univers Ω : ensemble des issues possibles.
  • Événement : sous-ensemble de Ω.
  • Événement élémentaire : un seul élément.
  • Événement certain : Ω. Impossible : ∅.

5.2 Probabilité

Sur un univers fini, on définit une probabilité P qui vérifie :

P(Ω) = 1   ;   0 ≤ P(A) ≤ 1   ;   P(A ∪ B) = P(A) + P(B) si A et B disjoints

5.3 Équiprobabilité

P(A) = (nombre d'issues favorables à A) / (nombre total d'issues)

5.4 Événement contraire et réunion

P(Ā) = 1 − P(A)
P(A ∪ B) = P(A) + P(B) − P(A ∩ B)
