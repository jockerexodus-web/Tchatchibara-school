Chapitre 1 — Le second degré

1. Définition d'un polynôme du second degré

Définition Un polynôme du second degré (ou trinôme) est une fonction de la forme :
f(x) = ax² + bx + c, avec a ≠ 0
où a, b et c sont des nombres réels appelés coefficients.

2. Forme canonique

Propriété Tout trinôme ax² + bx + c peut s'écrire sous sa forme canonique :
f(x) = a(x − α)² + β
avec α = −b/(2a) et β = f(α). Cette forme permet d'identifier le sommet S(α ; β) de la parabole.

3. Discriminant et résolution de ax² + bx + c = 0

Définition On appelle discriminant le réel :
Δ = b² − 4ac
Résolution selon le signe de Δ
  • Si Δ > 0 : deux solutions réelles distinctes x₁ = (−b − √Δ)/(2a) et x₂ = (−b + √Δ)/(2a).
  • Si Δ = 0 : une solution double x₀ = −b/(2a).
  • Si Δ < 0 : aucune solution réelle.

4. Factorisation

Propriété Si Δ ≥ 0, on peut factoriser :
ax² + bx + c = a(x − x₁)(x − x₂)
(avec x₁ = x₂ si Δ = 0).

5. Signe du trinôme

Règle du signe
  • Si Δ > 0 : le trinôme est du signe de a à l'extérieur des racines, et du signe de −a entre les racines.
  • Si Δ = 0 : le trinôme est du signe de a partout sauf en x₀ où il s'annule.
  • Si Δ < 0 : le trinôme est du signe de a sur ℝ tout entier.

6. Somme et produit des racines

Propriété Si x₁ et x₂ sont les racines de ax² + bx + c = 0 :
x₁ + x₂ = −b/a et x₁ × x₂ = c/a

7. Représentation graphique

Remarque La courbe est une parabole de sommet S(α ; β).
  • Si a > 0 : parabole tournée vers le haut (minimum en S).
  • Si a < 0 : parabole tournée vers le bas (maximum en S).
Exemple résolu Résoudre 2x² − 7x + 3 = 0.
Δ = (−7)² − 4×2×3 = 49 − 24 = 25 > 0.
√Δ = 5. Donc x₁ = (7 − 5)/4 = 1/2 et x₂ = (7 + 5)/4 = 3.
Solutions : S = {1/2 ; 3}.
Méthode — Équations se ramenant au second degré Pour résoudre une équation avec des fractions ou des racines, on se ramène à ax² + bx + c = 0 en multipliant par le dénominateur (en vérifiant les valeurs interdites), puis on applique la méthode ci-dessus.
Chapitre 2 — Fonctions et dérivation

1. Généralités sur les fonctions

Définition Une fonction f associe à chaque réel x d'un ensemble D (domaine de définition) un unique réel f(x). On note f : D → ℝ.
Sens de variation
  • f est croissante sur I si pour tous a, b de I avec a < b, on a f(a) ≤ f(b).
  • f est décroissante sur I si a < b ⟹ f(a) ≥ f(b).

2. Nombre dérivé

Définition Le nombre dérivé de f en a est la limite, si elle existe, du taux d'accroissement :
f′(a) = limh→0 [f(a+h) − f(a)] / h
Il correspond au coefficient directeur de la tangente à la courbe au point d'abscisse a.

3. Fonction dérivée — formules usuelles

Fonction f(x)Dérivée f′(x)
k (constante)0
x1
x²2x
xⁿn·xⁿ⁻¹
1/x−1/x²
√x1/(2√x)

4. Opérations sur les dérivées

Propriétés
  • (u + v)′ = u′ + v′
  • (k·u)′ = k·u′
  • (u·v)′ = u′v + uv′
  • (u/v)′ = (u′v − uv′)/v²

5. Lien dérivée / variations

Théorème fondamental
  • Si f′ > 0 sur I, alors f est strictement croissante sur I.
  • Si f′ < 0 sur I, alors f est strictement décroissante sur I.
  • Si f′ = 0 sur I, alors f est constante sur I.
Un changement de signe de f′ en un point a indique un extremum local.

6. Équation de la tangente

Propriété La tangente à la courbe de f au point d'abscisse a a pour équation :
y = f′(a)(x − a) + f(a)
Exemple résolu Soit f(x) = x³ − 3x. f′(x) = 3x² − 3 = 3(x² − 1).
f′ > 0 sur ]−∞ ; −1[ ∪ ]1 ; +∞[, f′ < 0 sur ]−1 ; 1[.
Donc f est croissante puis décroissante puis croissante : maximum local en x = −1 (f(−1) = 2), minimum local en x = 1 (f(1) = −2).
Méthode — Étude complète d'une fonction
  1. Déterminer le domaine de définition.
  2. Calculer la dérivée f′.
  3. Étudier le signe de f′.
  4. Dresser le tableau de variations.
  5. Calculer les valeurs remarquables et tracer la courbe.
Chapitre 3 — Suites numériques

1. Définition

Définition Une suite numérique (uₙ) est une fonction définie sur ℕ (ou une partie de ℕ) qui à chaque entier n associe un réel uₙ.

2. Suites arithmétiques

Définition (uₙ) est arithmétique de raison r si pour tout n :
uₙ₊₁ = uₙ + r
Propriétés
  • Terme général : uₙ = u₀ + n·r (ou uₙ = u_p + (n−p)·r).
  • Somme des n premiers termes : S = (nombre de termes) × (premier + dernier)/2.

3. Suites géométriques

Définition (uₙ) est géométrique de raison q (q ≠ 0) si :
uₙ₊₁ = q · uₙ
Propriétés
  • Terme général : uₙ = u₀ · qⁿ.
  • Somme des termes : S = u₀ × (1 − qⁿ⁺¹)/(1 − q) si q ≠ 1.

4. Sens de variation

Propriétés
  • Arithmétique : croissante si r > 0, décroissante si r < 0, constante si r = 0.
  • Géométrique (u₀ > 0) : croissante si q > 1, décroissante si 0 < q < 1.

5. Comportement à l'infini

Remarque
  • Si q > 1 : qⁿ → +∞.
  • Si 0 < q < 1 : qⁿ → 0.
  • Si −1 < q < 0 : qⁿ → 0 (alternée).
Exemple résolu (uₙ) arithmétique avec u₀ = 3 et r = 2 : uₙ = 3 + 2n. Somme des 10 premiers termes : S = 10 × (u₀ + u₉)/2 = 10 × (3 + 21)/2 = 120.
Chapitre 4 — Statistiques descriptives

1. Vocabulaire

Définitions
  • Population : ensemble étudié.
  • Caractère : propriété étudiée (quantitatif ou qualitatif).
  • Effectif : nombre d'individus d'une valeur.
  • Fréquence : effectif / effectif total.

2. Indicateurs de position

Propriétés
  • Moyenne : x̄ = (Σ nᵢxᵢ) / N.
  • Médiane : valeur qui sépare la série en deux parties égales.
  • Quartiles : Q₁ (25 %), Q₂ = médiane, Q₃ (75 %).

3. Indicateurs de dispersion

Propriétés
  • Étendue = max − min.
  • Écart interquartile = Q₃ − Q₁.
  • Variance : V = (1/N) Σ nᵢ(xᵢ − x̄)².
  • Écart-type : σ = √V.

4. Diagramme en boîte

Remarque Le diagramme en boîte (boîte à moustaches) représente min, Q₁, médiane, Q₃ et max. Il permet de comparer visuellement plusieurs séries.
Exemple résolu Série : 2, 4, 5, 7, 9, 10, 12.
Moyenne = (2+4+5+7+9+10+12)/7 = 49/7 = 7.
Médiane = 7 (4ᵉ valeur). Q₁ = 4, Q₃ = 10. Étendue = 12 − 2 = 10.
Chapitre 5 — Probabilités

1. Vocabulaire

Définitions
  • Expérience aléatoire : expérience dont on connaît les issues possibles mais pas le résultat.
  • Univers Ω : ensemble des issues possibles.
  • Événement : sous-ensemble de Ω.

2. Probabilité

Définition Une probabilité P est une fonction qui à chaque événement A associe un réel P(A) ∈ [0 ; 1] tel que P(Ω) = 1 et, pour deux événements incompatibles A et B, P(A ∪ B) = P(A) + P(B).
Propriétés
  • P(Ā) = 1 − P(A).
  • P(A ∪ B) = P(A) + P(B) − P(A ∩ B).
  • Équiprobabilité : P(A) = (nombre de cas favorables)/(nombre de cas possibles).

3. Probabilités conditionnelles

Définition La probabilité de A sachant B (avec P(B) ≠ 0) est :
P(A|B) = P(A ∩ B) / P(B)
Formule des probabilités totales Si B₁, B₂, …, Bₙ forment une partition de Ω :
P(A) = Σ P(A|Bᵢ) · P(Bᵢ)

4. Indépendance

Définition A et B sont indépendants si P(A ∩ B) = P(A)·P(B), c'est-à-dire P(A|B) = P(A).

5. Variable aléatoire

Définition Une variable aléatoire X associe un réel à chaque issue de Ω. On définit :
  • L'espérance : E(X) = Σ xᵢ·P(X = xᵢ).
  • La variance : V(X) = Σ (xᵢ − E(X))²·P(X = xᵢ) = E(X²) − [E(X)]².
  • L'écart-type : σ(X) = √V(X).
Exemple résolu On lance un dé équilibré. X = numéro obtenu.
E(X) = (1+2+3+4+5+6)/6 = 3,5.
V(X) = (1/6)[(1−3,5)² + … + (6−3,5)²] ≈ 2,92 ; σ(X) ≈ 1,71.
Chapitre 6 — Vecteurs et géométrie repérée

1. Vecteurs du plan

Définition Un vecteur AB→ est caractérisé par sa direction, son sens et sa norme (longueur). Deux vecteurs sont égaux s'ils ont même direction, même sens et même norme.
Coordonnées Si A(x_A ; y_A) et B(x_B ; y_B), alors :
AB→ (x_B − x_A ; y_B − y_A)

2. Opérations sur les vecteurs

Propriétés
  • Somme : u→ + v→ (addition des coordonnées).
  • Multiplication par un réel k : k·u→ (coordonnées multipliées par k).
  • u→ et v→ sont colinéaires si v→ = k·u→ (déterminant nul : x·y′ − x′·y = 0).

3. Équations de droites

Propriétés
  • Équation réduite : y = mx + p (m = coefficient directeur, p = ordonnée à l'origine).
  • Équation cartésienne : ax + by + c = 0.
  • Le vecteur directeur d'une droite d'équation ax + by + c = 0 est (−b ; a).

4. Produit scalaire (initiation)

Définition Le produit scalaire de u→(x ; y) et v→(x′ ; y′) est :
u→ · v→ = x·x′ + y·y′
Deux vecteurs sont orthogonaux si leur produit scalaire est nul.
Exemple résolu Droite passant par A(1 ; 2) et B(4 ; 6).
Vecteur AB→ (3 ; 4). Coefficient directeur m = 4/3.
Équation : y = (4/3)x + p. Avec A : 2 = (4/3)(1) + p ⟹ p = 2/3.
Donc y = (4/3)x + 2/3, soit 4x − 3y + 2 = 0.
Chapitre 7 — Trigonométrie

1. Cercle trigonométrique

Définition Le cercle trigonométrique est le cercle de centre O et de rayon 1, orienté dans le sens direct (sens inverse des aiguilles d'une montre).

2. Radians et degrés

Conversion
180° = π radians
Donc 1 rad ≈ 57,3° et 1° ≈ π/180 rad.

3. Cosinus et sinus

Définition Pour un point M du cercle trigonométrique associé à l'angle α, on a :
M(cos α ; sin α)
avec cos²α + sin²α = 1.

4. Valeurs remarquables

α0π/6π/4π/3π/2
cos α1√3/2√2/21/20
sin α01/2√2/2√3/21

5. Formules d'addition

Propriétés
  • cos(a + b) = cos a cos b − sin a sin b
  • cos(a − b) = cos a cos b + sin a sin b
  • sin(a + b) = sin a cos b + cos a sin b
  • sin(a − b) = sin a cos b − cos a sin b

6. Équations trigonométriques

Méthode
  • cos x = cos α ⟺ x = α + 2kπ ou x = −α + 2kπ.
  • sin x = sin α ⟺ x = α + 2kπ ou x = π − α + 2kπ.
Exemple résolu Résoudre cos x = 1/2 sur [0 ; 2π].
cos x = cos(π/3) ⟹ x = π/3 ou x = −π/3 + 2π = 5π/3.
S = {π/3 ; 5π/3}.
Chapitre 8 — Nombres et calculs

1. Nombres réels et intervalles

Définition L'ensemble des réels ℝ contient tous les nombres (rationnels et irrationnels). Les intervalles sont notés [a ; b], ]a ; b[, [a ; +∞[, etc.

2. Racines carrées

Propriétés
  • √(ab) = √a · √b (pour a, b ≥ 0).
  • √(a/b) = √a / √b (b > 0).
  • √(a²) = |a|.

3. Puissances

Propriétés
  • aᵐ · aⁿ = aᵐ⁺ⁿ
  • aᵐ / aⁿ = aᵐ⁻ⁿ
  • (aᵐ)ⁿ = aᵐⁿ
  • a⁻ⁿ = 1/aⁿ
  • a⁰ = 1 (a ≠ 0)

4. Valeur absolue

Définition |x| = x si x ≥ 0, et |x| = −x si x ≤ 0. Géométriquement, |x| est la distance entre x et 0.
Propriétés
  • |xy| = |x|·|y|
  • |x| = |y| ⟺ x = y ou x = −y
  • |x| ≤ r ⟺ −r ≤ x ≤ r
  • Inégalité triangulaire : |x + y| ≤ |x| + |y|

5. Ordre et inégalités

Propriétés
  • Si a ≤ b, alors a + c ≤ b + c.
  • Si a ≤ b et c > 0, alors ac ≤ bc.
  • Si a ≤ b et c < 0, alors ac ≥ bc (inversion du sens).
Exemple résolu Résoudre |2x − 3| ≤ 5.
⟺ −5 ≤ 2x − 3 ≤ 5
⟺ −2 ≤ 2x ≤ 8
⟺ −1 ≤ x ≤ 4. S = [−1 ; 4].
Chapitre 9 — Algorithmique et Python

1. Notion d'algorithme

Définition Un algorithme est une suite finie d'instructions permettant de résoudre un problème. Il peut être traduit en langage de programmation (Python, par exemple).

2. Variables et affectation

Propriétés Une variable stocke une valeur. En Python : x = 5 affecte 5 à x. On peut aussi affecter plusieurs variables : a, b = 1, 2.

3. Instructions conditionnelles

Exemple 
if x > 0:
    print("positif")
elif x == 0:
    print("nul")
else:
    print("négatif")

4. Boucles

Boucle for 
for i in range(5):
    print(i)   # affiche 0,1,2,3,4
Boucle while 
n = 0
while n < 5:
    n = n + 1

5. Fonctions

Exemple 
def carre(x):
    return x * x

print(carre(4))   # 16

6. Applications mathématiques

Exemples d'algorithmes utiles
  • Calcul de la somme des n premiers entiers.
  • Recherche du maximum d'une liste.
  • Résolution approchée d'équations (dichotomie).
  • Simulation de tirages aléatoires (module random).
Exemple complet — Somme 1 + 2 + … + n 
def somme(n):
    s = 0
    for i in range(1, n+1):
        s = s + i
    return s

print(somme(10))   # 55
